DUCPHU COMMERCE

Nền tảng thương mại điện tử Full-stack gồm storefront, xác thực, giỏ hàng, thanh toán, lịch sử đơn hàng và Admin CMS được bảo vệ theo vai trò.

  • Thiết kế 66 REST API routes và 19 bảng MySQL theo kiến trúc Controller–Service–Repository, sử dụng PDO, transaction và row locking.
  • Tích hợp PayOS, webhook ký HMAC, idempotency và reconciliation để đồng bộ trạng thái thanh toán và đơn hàng.
  • Bổ sung JWT, phân quyền, upload an toàn, rate limiting, audit log và quality gates với Vitest, Playwright, PHP/MySQL tests.
